# Steam Games Market Analysis

**What drives a game's commercial success and player satisfaction on Steam?**

An end-to-end analytics project using SQL, Power BI, and AI-powered review analysis, framed around the questions a game publisher like Rockstar Games asks: which genres and pricing strategies win, how discounts affect reception, and what players actually complain about.

> 🚧 Work in progress. This README is updated at every stage.

## Tools
- **SQL** (SQLite): data cleaning, exploration, business queries
- **Power BI**: interactive dashboard
- **Claude API**: classifying player reviews by theme and sentiment at scale
- **Python**: data pipeline glue

## Data
[Game Recommendations on Steam](https://www.kaggle.com/datasets/antonkozyriev/game-recommendations-on-steam) (Kaggle): game metadata, prices, ratings, and user recommendations.
